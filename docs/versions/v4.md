## Communication Discipline (added v4.6)

All agents follow the rule in `solar.instructions.md § Communication Discipline` and `AGENTS.md § Usage`:

- Work silent, signal only
- Emit one-line stage signals, `BLOCKED:` notices, and final artifacts
- No narration of tool calls, no preamble, no prose summaries of completed actions

The rule is embedded in the installer (Step 5E) so every new installation generates it automatically.
