## Pipelines

| #   | Name       | Description                                                  | Stages                                                                                             |
| --- | ---------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| 1   | Knowledge  | Question answering from injected context                     | Governor → direct answer                                                                           |
| 2   | Simple Fix | Small, scoped code changes                                   | Governor → Implementation → close                                                                  |
| 3   | Bug Fix    | Bug reproduction, root-cause, targeted repair                | Governor → Bug Investigation → Implementation → Review → close                                     |
| 4   | Feature    | Full vertical slice with design, implementation, tests, docs | Governor → Design → Implementation → Test → Review → Security (conditional) → Release Gate → close |

**Stage 4 (Security Auditor) trigger:** Binary file-pattern check — mandatory if any changed file matches `*route*`, `*auth*`, `*middleware*`, `*config*`, `*controller*`, `*permission*`, `*secret*`, `*credential*`. No qualitative judgment allowed.

## Hooks

| Event            | File                     | Active Modes | What it does                                                                                                                            |
| ---------------- | ------------------------ | ------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| PreToolUse       | `pre-tool-use.cjs`       | all          | Blocks `agent` tool calls if Stage 1 (Design Planning Architect) has not completed; bypasses Design/Architect/Bug Investigation targets |
| UserPromptSubmit | `user-prompt-submit.cjs` | loop         | Context injection from ledger; blocks new prompt if a task is still pending                                                             |
| PostToolUse      | `post-tool-use.cjs`      | loop         | Runs `tsc --noEmit` after write operations; injects type errors as backpressure                                                         |
| Stop             | `stop.cjs`               | loop         | Enforces loop continuation if completion promise absent; silent in chat mode                                                            |

**Config file:** `.github/solar.config.json`  
**Kill switch:** `solar.active: false` (current default — flip to `true` to activate)

## Memory Architecture

| Layer          | Location                | Scope                  | Purpose                                                                                     |
| -------------- | ----------------------- | ---------------------- | ------------------------------------------------------------------------------------------- |
| Ledger         | `.github/.ai_ledger.md` | Session                | Active execution state, blockers, stage outcomes                                            |
| Repo memory    | `/memories/repo/`       | Repository             | Verified facts: commands, architecture, workflow, frontend, backend, security, verification |
| Session memory | `/memories/session/`    | Single conversation    | In-progress notes, cleared on exit                                                          |
| User memory    | `/memories/`            | User (cross-workspace) | User preferences and patterns                                                               |
